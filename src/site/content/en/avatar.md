# Avatar

A person's initials in a colored circle, or their photo. The color stays the same for the same person.

@example avatar 180
```tsx
import { Avatar } from "stackui";

<Avatar name="Ana Souza" />
<Avatar name="Leo Park" size={56} />
<Avatar name="Maya" src="/photos/maya.jpg" size={64} />
```
