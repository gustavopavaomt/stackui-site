# Card

A rounded surface. Give it `href` or `onClick` and the whole card becomes tappable.

@example card 220
```tsx
import { Card, Text } from "@stackui/react";

<Card href="/goals">
  <Text font="headline">Monthly goal</Text>
  <Text color="secondary">72% reached, 8 days left</Text>
</Card>
```
