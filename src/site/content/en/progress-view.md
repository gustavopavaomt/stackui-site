# ProgressView

The activity indicator: eight spokes that light up in turn. It takes the color of the text around it.

@example progress-view 160
```tsx
import { HStack, ProgressView, Text } from "stackui";

<HStack spacing={12}>
  <ProgressView />
  <Text color="secondary">Loading…</Text>
</HStack>
```
