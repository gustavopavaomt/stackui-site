# ProgressView

O indicador de atividade: oito raios que acendem em roda. Ele pega a cor do texto em volta.

```tsx
import { HStack, ProgressView, Text } from "stackui-kit";

<HStack spacing={12}>
  <ProgressView label="Carregando" />
  <Text color="secondary">Carregando…</Text>
</HStack>
```
