# Card

Uma superfície arredondada. Com `href` ou `onClick`, o cartão inteiro vira tocável.

@example card 220
```tsx
import { Card, Text } from "stackui-kit";

<Card href="/metas">
  <Text font="headline">Meta do mês</Text>
  <Text color="secondary">72% alcançada, faltam 8 dias</Text>
</Card>
```
