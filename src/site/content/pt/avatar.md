# Avatar

As iniciais de uma pessoa num círculo colorido, ou a foto dela. A cor é sempre a mesma para a mesma pessoa.

@example avatar 180
```tsx
import { Avatar } from "stackui";

<Avatar name="Ana Souza" />
<Avatar name="Leo Park" size={56} />
<Avatar name="Maya" src="/fotos/maya.jpg" size={64} />
```
